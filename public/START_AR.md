# ابدأ أكاديمية التسويق على Windows

## التشغيل الأول

1. نزّل `Marketing-Academy-Portable-Windows-x64.exe` من إصدار GitHub الرسمي. الملف EXE واحد؛ لا تفك شيفرته ولا تغيّر امتداده.
2. احفظه في مجلد عادي قابل للكتابة مثل «التنزيلات». افتحه بالنقر المزدوج وانتظر ظهور نافذة الأكاديمية؛ الاستخراج المؤقت في التشغيل الأول قد يستغرق قليلًا.
3. لا تثبّت Node.js أو Python أو Docker أو قاعدة بيانات، ولا تفتح نافذة أوامر. هذه الأدوات ليست مطلوبة لاستخدام التطبيق.
4. اختر «إنشاء حساب»، واكتب اسمًا وكلمة مرور من12 إلى128 حرفًا، ثم أكمل إعداد الدراسة. احتفظ بكلمة المرور في مكان آمن؛ لا توجد استعادة عبر البريد. يمكنك الاستعادة إلى حساب جديد من نسخة مشفرة وعبارة حمايتها.
5. افتح الدرس الأول. اقرأ الشرح وجرّب الأنشطة ثم الاختبار والتطبيق. حد اجتياز الاختبار70٪. إكمال الخانات أو المراجعة الذاتية ليس اعتمادًا مهنيًا.

## الملاحظات والحفظ والخروج

اضغط الدائرة الصغيرة بجانب عنوان الدرس لفتح ملاحظاته. لكل حساب ملاحظات وتقدم وتسليمات مستقلة. انتظر إشارة الحفظ قبل الإغلاق. أغلق النافذة ثم افتح الملف نفسه؛ سجّل الدخول بالحساب نفسه لاستعادة بياناتك. لا حاجة للإنترنت للدروس والاختبارات والأنشطة والملاحظات والمشروعات؛ فتح مواقع المراجع يحتاج الإنترنت.

بياناتك محفوظة في مساحة بيانات التطبيق في حساب Windows، وليست داخل ملف EXE. نسخ EXE إلى جهاز آخر لا ينقل تقدمك تلقائيًا، وحذف بيانات التطبيق أو ملف تعريف Windows قد يفقدها. المستخدمون على الجهاز نفسه منفصلون بتسجيل الدخول؛ صاحب صلاحيات إدارة الجهاز ليس خارج حدود الثقة.

## النسخة الاحتياطية ونقل الجهاز

من «الإعدادات» اختر عبارة حماية مستقلة من12 إلى128 حرفًا ثم «نزّل نسخة مشفّرة». احفظ ملف `.academy` وعبارته بأمان خارج الجهاز. للاستعادة: أنشئ/افتح الحساب المقصود، وأدخل عبارة النسخة، واختر الملف ثم «استعد النسخة واستبدل البيانات». الاستعادة تستبدل بيانات الحساب الحالي بعد التحقق؛ صدّر نسخة منه أولًا. ملفات Markdown وPDF لعرض ملف الأعمال وليست بديلًا لنسخة الاستعادة. لا توجد مزامنة سحابية تلقائية.

## التحديث

أغلق النسخة القديمة بعد الحفظ، وصدّر نسخة احتياطية، ثم نزّل EXE الجديد وافتحه على حساب Windows نفسه. لا تحذف بيانات التطبيق ولا تشغّل نسختين معًا. اسم الملف ثابت، لذا قد يضيف المتصفح `(1)` عند تنزيل إصدار آخر؛ اختر النسخة التي نزّلتها من الإصدار المطلوب. احتفظ بالنسخة السابقة والنسخة الاحتياطية حتى تتأكد من بياناتك. لا يوجد ضمان مُختبر لكل جهاز أو لكل انتقال بين إصدارات قديمة.

## تحذير SmartScreen وحدود الدعم

الملف غير موقّع رقميًا، وقد يعرض Windows SmartScreen رسالة أن الناشر غير معروف، وقد تمنع سياسة جهاز العمل تشغيله. لا تعطّل مضاد الفيروسات أو سياسات مؤسستك. تحقق أولًا من مصدر التنزيل وبصمة SHA‑256 في `SHA256SUMS.txt`؛ إذا لم تستطع التأكد، لا تشغّل الملف واطلب مساعدة موثوقة. لا تحتاج صلاحيات مسؤول للاستخدام العادي، لكن سياسات الجهاز قد تفرض قيودًا.

الحزمة مخصصة لـWindows x64 الحديث؛ فُحصت على مشغّل Windows فعلي في GitHub Actions. مشغّل CI يحتوي أدوات تطوير لحزمة الاختبار، لذلك لا يساوي جهاز مستخدم نظيفًا أو اختبار نقر يدوي على كل إصدار Windows. تشغيل EXE الفعلي يُختبر بمسار بحث خالٍ من Node/Python/Docker وأدوات التطوير، مع اختبار الحساب والملاحظات والاختبار والتطبيق وإعادة الفتح والعزل. نتيجة التنفيذ الدقيقة في `verification.json`، ولا يكفي نجاح بناء المصدر لإثباتها. لا يُدّعى دعم Windows7/8 أو ARM أو32-bit أو كل جهاز فعلي.

المحتوى عربي RTL، وبيانات أمثلة الحملات محاكاة وليست مبيعات حقيقية. المراجعة التعليمية البشرية المستقلة وتجربة مبتدئ مستقلة ما زالتا مفتوحتين. إن منع الجهاز التشغيل، احتفظ بالنسخة الاحتياطية واذكر نص رسالة Windows وإصدار النظام عند طلب المساعدة؛ لا ترسل كلمة المرور أو قاعدة البيانات أو النسخة الخاصة علنًا.

## ملفا Production وQA

- للاستخدام الأساسي افتح `Marketing-Academy-Portable-Windows-x64.exe`؛ يحتفظ بمسار بيانات النسخ السابقة.
- للاختبار افتح `Marketing-Academy-QA-Windows-x64.exe`. ستظهر علامة QA وعنوان نافذة «QA معزولة». استخدم حسابات وملاحظات تجريبية فقط.
- يمكن فتح النسختين معًا. حسابات QA وقاعدة بياناتها وذاكرة متصفحها منفصلة؛ الاسم نفسه في النسختين لا يربط الحسابين. تغيير اسم EXE لا يغيّر نوع النسخة.
- لا تستورد نسخة احتياطية شخصية إلى QA إلا إذا أردت صراحة إنشاء نسخة من بياناتك فيها. لا توجد مزامنة تلقائية بين النسختين، ولا تحذف مجلد بيانات Production لاختبار QA.
- كلمة Production تصف النسخة الأساسية للاستخدام، ولا تعني اعتمادًا تعليميًا بشريًا أو شهادة توقيع Windows. كلا الملفين غير موقعين، وتبقى حدود التحقق المذكورة أعلاه سارية.

## نسيان كلمة المرور

من شاشة الدخول اختر «نسيت كلمة المرور؟ استعادة من نسخة مشفرة». اختر نسخة `.academy` وأدخل عبارة حمايتها، ثم اسمًا جديدًا وكلمة مرور جديدة. تُنشأ هوية مستقلة ببيانات النسخة؛ الحساب القديم وكلمته وبياناته لا تتغير. تُرفض العبارة الخاطئة والاسم المستخدم سابقًا. بدون كلمة المرور أو نسخة مشفرة وعبارتها لا يستطيع التطبيق فك بيانات الحساب، ولا توجد استعادة بالبريد أو مزامنة سحابية. في النسخة المتصفح المحلية القديمة دون API: أنشئ حسابًا جديدًا ثم استعد النسخة من الإعدادات.

لتغيير كلمة المرور وأنت مسجل: افتح الإعدادات وأدخل الكلمة الحالية والجديدة. بعد إغلاق التطبيق تحتاج تسجيل الدخول مجددًا؛ حفظ البيانات دائم، أما جلسة الدخول فمؤقتة. حد كلمات مرور الحسابات الجديدة١٢–١٢٨ نقطة Unicode؛ لا تُحذف المسافات ولا تُطبّع كلمة المرور.

# Marketing Academy2.2.0 — project learning preview

A portable Arabic RTL Windows application with60 lessons across12 modules. This release extends the verified2.1.1 application with12 complete worked module guides,60 original lesson mini-projects with solutions/templates, and three fully worked Iraqi restaurant/clothing/e-commerce capstones. Each module guide includes objectives, prerequisites, materials/concepts, detailed steps, full solution, editable template, deliverables, self-assessment and common mistakes/improvement advice.

The capstone progresses through12 stages/27 fields: research, personas, competitors, positioning, storytelling, SMART goals, the nine-part plan, content calendars, five social posts, two ads, simulated budgets, KPIs, campaign analysis and client report. All example observations/prices/results are fictional simulations. No paid advertising, platform account, external subscription or live campaign is required to complete the training.

Module submissions, lesson practice and capstone edits now autosave with a saved-state indicator, serialized writes and retry on failure. Module switching/export waits for the latest acknowledged draft. Existing user IDs, worked artifacts, rubrics, completed credit, guide/assessment history and26-field backups are preserved. A new optional competitor field requires no destructive database migration. Preview-and-confirm transfer appends module submissions without replacing prior portfolio text. Full Markdown portfolios include assignments/module submissions; focused client reports, printable outputs and encrypted backup/restore are available.

The Windows x64 EXE includes its own runtime and native SQLite. It requires no Node.js, Docker, external backend or normal-use configuration. SQLite accounts retain separate encrypted records and secure authentication. Local accounts do not automatically synchronize devices; transfer a validated encrypted backup explicitly. The optional Docker Compose web/API edition uses the shared curriculum and business logic.

# Marketing Academy2.3.0 — Production and isolated QA Windows preview

Two genuine portable x64 EXEs: Marketing-Academy-Portable-Windows-x64.exe (Production) and Marketing-Academy-QA-Windows-x64.exe (QA). Both bundle the same Arabic RTL60-lesson/12-module interactive curriculum, projects, runtime and encrypted SQLite accounts. Neither requires Node.js, Python, Docker, database software or an external backend for normal use.

Production identity/userData/schema/IDs are preserved. QA has its own packaged identity, database, Chromium storage/cache and single-instance lock, with an Arabic QA banner/window title. The same account name in both remains independent. QA does not automatically read or migrate Production data. Explicitly importing a backup into QA deliberately copies its data; use synthetic QA data.

Exact-source Windows CI must run both real EXEs: normal ShellExecute without arguments with a system-only child PATH; registration/notes/offline quiz+lesson/restart/saved attempts/projects and legacy migration for each; simultaneous identical-name accounts with separate notes and a byte-hash check that QA writes do not change the closed Production database. verification.json records actual outcomes, sizes, PE/x64 payloads and the tested commit. Separate SHA256 entries, source ZIP and Arabic START_AR.md accompany both EXEs.

Unsigned: SmartScreen/enterprise policy restrictions may apply. A Windows Actions runner is not a pristine consumer PC/manual Explorer double-click/every physical device or version-to-version upgrade test. Production names the normal data profile, not independent professional educational approval. Human Arabic review/novice validation and assessment moderation remain open; fictional campaign data remain simulations. This is a working prerelease; prior releases and latest stablev2.0.0 are retained.

# Marketing Academy 2.1.1 — working preview

A portable Arabic RTL Windows application with60 original lessons across12 progressive modules,300 explained assessment questions,360 saved learning activities,60 practical assignments,12 worked module projects and a portfolio capstone. The EXE operates independently without Node.js, Docker, an external server or normal-use configuration. It is unsigned.

Local accounts use SQLite authority with encrypted owner-isolated records, password hashing, session controls, transactional persistence, authenticated non-destructive migration and validated export/restore. Separate accounts retain their own progress, notes, attempts, assignments and projects. The circular lesson notebook supports autosave/search/timestamps. Local accounts do not automatically synchronize across devices. Optional Docker Compose provides same-origin web/API services with durable SQLite storage.

Patch2.1.1 preserves the original three-step guide-v1 completion rule in expanded lessons. Additional paragraphs stay available as optional guided depth, with saved acknowledgements; previously earned activity credit is retained, and existing five-step/notes/quiz records are unchanged. This fixes a progress-display regression in the2.1.0 preview without deleting or rewriting learner records.

This preview includes a second agent editorial/source pass over all60 lessons.45 later lessons gained substantive decision procedures, counterexamples and worked fictional Iraqi cases;10 foundational cases gained solutions, and module3 depth was retained.84 questions were revised while historical wording and grades remain available through assessment versions. A26-entry source registry links bounded references, access and rights notes to lessons; copyrighted books/PDFs and private data are excluded. RFC9989 replaces the obsolete DMARC reference.

**Educational limits:** no qualified independent human Arabic review, learner validation, psychometric calibration or professional accreditation is claimed.109 uniquely-longest-correct answers remain moderation candidates. Free-text workshops/projects use explicit structural/self-review. Provider catalogues with unestablished content permissions are optional human resources, not ingested courses. Source mapping is bounded, not a claim that every sentence or source is exhaustively covered. A preview is a working package for use and review; it does not declare all master-contract readiness gates complete. v2.0.0 remains latest stable.

**Verification:** published verification.json identifies the exact source commit and successful Windows/web/Docker run,50 unit/integration tests per OS and22 browser paths. The actual built x64 EXE is tested for native SQLite, profile/note/timestamp/activity persistence after restart, blocked external fetch and intact legacy migration. Docker health/security/owner-isolation persistence is tested. Checksums and a source archive accompany the EXE. Automated accessibility checks do not prove universal WCAG conformance or physical-device/screen-reader coverage.

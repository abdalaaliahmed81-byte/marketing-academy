# Marketing Academy 2.0.0

Arabic RTL local marketing education application, continuing the uploaded MVP.

- 60 original lessons across 12 progressive modules, 300 questions with explanations, 60 practical activities, daily missions and mistake reviews.
- 12 worked module projects, editable self-reviewed submissions, and a fully worked simulation capstone with portfolio exports.
- Small circular lesson-note controls with persistent lesson-specific editors, responsive layouts and reduced-motion support.
- Local registration/login/logout, per-account encrypted persistence, password changes, migrations and passphrase-encrypted validated backup/restore.
- Portable Windows x64 EXE with the application runtime bundled; no installed Node.js, Docker, development tools, external server or normal-use configuration required.
- Optional Docker Compose deployment of the same curriculum and business logic. Web accounts and data remain local to each browser profile/origin, not a centralized multi-device account service.

All sample business data and worked campaign results are simulations. Content underwent agent editorial/structural checks and arithmetic verification; no independent human instructor accreditation or certification is claimed. No proprietary PDF books or learner databases are included.

The Windows executable is unsigned. It may show a Windows reputation prompt. This release does not provide ARM64/native macOS packages. See docs/QA.md for exact executed evidence and known limitations, and docs/SECURITY.md for the local-device threat model.

Release assets: Windows EXE, source archive and SHA256SUMS.txt. Compare SHA-256 before running a downloaded artifact. The release workflow refuses to publish unless verification succeeded for the exact source commit.

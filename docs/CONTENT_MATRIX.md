## المشروعات والتخرج

كل مشروع من الاثني عشر يحتوي تكليفًا وأربعة مخرجات وست خطوات مفصلة وروبركًا وحلًا ونموذج تسليم محفوظًا. النماذج تعلن المحاكاة، ومقال الوحدة٦ يتجاوز٣٠٠ كلمة. التخرج يغطي٢٧ حقلًا في١٢ مرحلة مع ثلاثة أمثلة كاملة، وتوجد حسابات مستقلة للمثال الإعلاني. لكل درس مشروع مصغر إضافي بحل وقالب. راجع [مصفوفة المشروعات](PROJECT_LEARNING_MATRIX.md). بقي تقييم جودة التسليم ذاتيًا؛ لا يوجد حكم مدرس أو قياس تعلم قبلي/بعدي. لا تسمي إكمال الخانات دليل كفاءة مهنية أو اعتمادًا.

## التفاعلات المحفوظة

كل درس يعرض ستة أنشطة فعلية محفوظة، بإجمالي360 نشاطًا. التوزيع الكامل ومعرفات النسخ في [INTERACTION_MATRIX.md](INTERACTION_MATRIX.md). لا تلغي إضافة التفاعل ملاحظات عمق المحتوى أو المراجعة البشرية أعلاه.

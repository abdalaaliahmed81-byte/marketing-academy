## فتح التطبيق

نزّل Marketing-Academy-Portable-Windows-x64.exe من الإصدار واحفظه في مجلد عادي، ثم افتحه بالنقر المزدوج وانتظر ظهور النافذة. لا تثبت Node.js أو Python أو Docker أو برنامج قاعدة بيانات. أنشئ حسابًا محليًا بكلمة مرور12–128 حرفًا وابدأ الدرس الأول. انتظر إشارة الحفظ قبل الإغلاق، وافتح الملف نفسه وسجل الدخول بالحساب نفسه عند العودة. صدّر نسخة مشفرة من الإعدادات قبل النقل أو التحديث؛ نسخ EXE وحده لا ينقل التقدم ولا توجد مزامنة سحابية تلقائية. الملف غير موقع وقد يعرض SmartScreen تحذير ناشر مجهول؛ تحقق من المصدر والبصمات ولا تعطّل حماية الجهاز أو سياسات المؤسسة.

## الإجراء الخارجي الضروري الوحيد المطلوب الآن

رفض GitHub طلب جعل المستودع خاصًا بخطأ403 Resource not accessible by integration. بيانات الحساب تظهرadmin=true، لكن رمز الاتصال لا يستطيع تنفيذ تعديل الإعدادات. غيّر المستودع نفسه من Settings → General → Danger Zone → Change repository visibility إلى Private، حفاظًا على السجل والإصدارات. بعدها نعيد التحقق من الوصول والتنزيل عبر الحساب المصرح ونرفع تقرير القبول إلى المستودع الخاص. لا يجعل ذلك المراجعة التعليمية البشرية منفذة.

هذا التقرير محفوظ محليًا إلى حين استيفاء الخصوصية؛ لم تُرفع إضافات إلى المستودع العام بعد طلب الخصوصية الحالي. لم يُعلن اكتمال المشروع أو اعتماد المحتوى مهنيًا. لا عيب تقني حرج/مرتفع معروف ضمن نطاق الأدلة المقروءة؛ لا يُستنتج من ذلك تحقق شامل.

## سياسة العمل

الكتب المرفقة مراجع مفاهيمية خاصة؛ بقيت الملفات والمستخرجات خارج Git. لم تنقل جداولها أو قصصها أو مقتطفاتها إلى المنهج. فصلنا القراءة عن إعادة الاستخدام، والحقائق العامة عن صياغة صاحب المصدر. لم نجلب دورات Semrush أو Meta أو HubSpot أو Skillshop بوصفها مادة تأليف. فحص الشروط أو بيانات الفهرس لا يساوي إذن إدخال محتوى الدورات إلى AI. تعذر فتح CISA بخطأ403 ولم نتجاوزه؛ استُخدم مرجع Google Cloud المسموح بدلًا منه لمبدأ أقل صلاحية. عناوين تخمينية غير صحيحة لـGA campaigns وOpenStax introduction أعادت404؛ ليست مراجع معتمدة في الدروس. OpenStax مورد اختياري فقط بسبب اختلاف الترخيص المعروض بين نتائج الويب/PDF، ولا نفترض أن النسخة القابلة للقراءة تمنح إعادة التوزيع.

المراجع التقنية المتغيرة تفحص قبل تنفيذ فعلي؛ صفحات الكتب وأقسام NIST/RFC تأسيسية وليست تعليمات واجهة حديثة. لا يعتمد أي مثال عراقي على إحصاء سوق أو عميل موثق؛ جميع الأسماء والأعداد محاكاة تعليمية مؤلفة. عدم وجود دراسة ميدانية مصرح به. لم تُجرَ معايرة سيكومترية أو مراجعة مدرس مستقل.

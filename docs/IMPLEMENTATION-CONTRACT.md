## قواعد التنفيذ

- لا تُرفع الكتب أو النصوص المستخرجة أو ملفات بيانات المستخدمين أو الرموز السرية إلى Git.
- لا يُنشر المستودع علنًا. لا يُرفع إصدار نهائي قبل اجتياز بوابات الجودة المتاحة وبيان أية فجوة.
- يختار التنفيذ التقني بعد فحص المشروع. الأساس الحالي React/TypeScript/Dexie محفوظ.
- فصل المنطق التعليمي عن التغليف المكتبي. لا يصبح Docker أو خادم خارجي اعتمادًا لنسخة EXE.
- الاختبارات الآلية والمراجعة الذاتية لا تعني مراجعة بشرية مستقلة. تُسمّى جهة المراجعة وطريقتها بدقة.
- كلمات المرور لا تؤمّن جهازًا أو نظام تشغيل مخترقًا؛ تُوثّق حدود العزل والتشفير دون ادعاء حماية مطلقة.
- يُسجّل كل قرار جوهري وحالة مانع في docs، مع أوامر إعادة التحقق.

## الحالة الأولية المثبتة

الأرشيف: 43 مدخلًا و1,013,954 بايت بعد فك الضغط. React 19 وVite 6 وDexie 4 وZod 3. عشرة دروس في وحدتين، 50 سؤالًا، بقية الوحدات أسماء فقط. يوجد حفظ ملاحظات نصي داخل صفحة الدرس، ومهام يومية ومحرر ملف أعمال وتصدير JSON. لا توجد حسابات محلية أو ملفات Electron أو Docker أو workflows في الأرشيف. يحتوي الأرشيف dist قديمًا؛ سيُعاد بناؤه من المصدر.

اختبارات المصدر الأصلي لم تُعتبر ناجحة قبل تشغيلها. Node وPython وChromium وDocker متاحة في Linux؛ لا يوجد Windows محلي.

## GitHub

المستخدم أذن صراحة بإنشاء مستودع على حسابه ورفع المشروع. إنشاء مستودع خاص باسم marketing-academy فشل عبر gh repo create وعبر REST POST /user/repos بالرسالة: Resource not accessible by integration (HTTP 403). هذه صلاحية اتصال GitHub، وليست رفضًا من المراجعة التلقائية للأوامر. يستمر التنفيذ المحلي؛ يُستأنف الرفع عند إتاحة المستودع.

## تحديث الوصول

أصبح المستودع marketing-academy متاحًا، وكان عامًا. بعد توضيح الخصوصية ورفض GitHub تغيير الإعدادات، أجاز المستخدم صراحة «اكمل عليه كما هو». رُفع المصدر إلى المستودع العام بهذا الإذن، مع استمرار استبعاد الكتب والبيانات والأسرار. سجل فشل الإنشاء أعلاه تاريخي ولا يمثل مانع وصول حاليًا. الاعتماد النهائي للحزمة مرتبط بأدلة CI لنفس commit وسجل verification.json في الإصدار.


## تعديل عقد التدقيق والمعمارية —٢.١.٠ غير منشور

طلب التدقيق اللاحق يلزم SQLite للحسابات والتقدم خارج renderer، وواجهة React/TypeScript مشتركة، وAPI اختياري داخل Docker وبناء Windows فعلي. نُفذت هذه المعمارية مع حفظ IndexedDB القديم ومصدره وعدم تغيير هوية التطبيق أو معرفات التعلم. وثائق AUDIT وARCHITECTURE وFEATURE_MATRIX وCONTENT_MATRIX وAI_PROGRESS وRELEASE_GATES هي سجل الحالة الحالي. نجاح التحقق التقني لا يغلق فجوات عمق٥٠ درسًا ولا المراجعة العربية المستقلة؛ لا يُعلن اكتمال المنصة التعليمية المتقدمة. الإصدار المنشور٢.٠.٠ محفوظ، ولا يوجد إصدار٢.١.٠ منشور بهذا التدقيق.

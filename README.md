تطبيق تعلّم عربي RTL بُني باستكمال مشروع MVP المرفق، مع ٦٠ درسًا في ١٢ وحدة و٣٠٠ سؤال، ومهام ومراجعات وملاحظات مستقلة لكل درس. يشمل ١٢ مشروع وحدة محلولًا وملف أعمال متكاملًا بنموذج محاكاة قابل للتحرير.

> هذا الفرع يحتوي المعاينة المنشورة٢.٢.٢، مع SQLite ومراجعة المحتوى وحفظ تاريخ التقييم. الإصدار المستقر٢.٠.٠ يستخدم IndexedDB؛ راجع [التدقيق](docs/AUDIT.md) و[بوابات الإصدار](docs/RELEASE_GATES.md). وجود٦٠ درسًا لا يعني اعتمادًا مهنيًا: اكتمل التعميق التحريري الآلي للدروس الستين، وتبقى المراجعة العربية البشرية المستقلة ومعايرة التعلم مفتوحتين. سجل المصادر يميز الإحالات المحددة والحقوق عن بوابات التعلم الاختيارية.

## استخدام Windows

نزّل EXE من قسم **Releases** وافتحه مباشرة. لا تحتاج تثبيت Node.js أو Docker أو خادم أو أدوات تطوير أو إعداد يدوي. أنشئ حسابًا محليًا بكلمة مرور طويلة، وحدد هدف الدراسة، ثم ابدأ المسار. تقدمك وملاحظاتك ومشروعاتك محفوظة مشفّرة على الجهاز ومفصولة عن الحسابات الأخرى. إغلاق التطبيق أو تسجيل الخروج يتطلب دخولًا جديدًا.

زر الملاحظات الدائري الملاصق لعنوان الدرس يفتح دفتره الخاص دون فتح الدرس. يدعم الحفظ التلقائي والبحث ووقت آخر تعديل وحالة الحفظ، وتبقى الملاحظات بعد إعادة التشغيل لكل حساب. مكتبة الموارد تبحث في الدروس والمراجع و«ملاحظاتي»، وإحصاءات التقدم تعرض المحاولات والنشاط والمشروعات الفعلية. الواجهة عربية RTL متجاوبة، مع وضع داكن وحركة مخففة عند تفضيل ذلك. كل درس يعرض شرحًا موجّهًا ومطابقة وترتيبًا وفراغًا وسيناريو متفرعًا وورشة مرتبطة بموضوعه. تُحفظ الإجابات والخطوات، ويمكن نقل ناتج الورشة إلى ملف الأعمال بعد مراجعة الاستبدال. يحفظ الاختبار اختياراتك قبل التسليم، وتبقى المحاولات عند الإعادة، وتظهر الأخطاء في مراجعات متباعدة. بعد اجتياز الاختبار وحفظ التطبيق والمراجعة الذاتية يتاح الدرس التالي؛ لا تُلغى إنجازات النسخ السابقة. يظهر مشروع كل وحدة مع التكليف والخطوات والنموذج المحلول. «مشروعي» يجمع ملف الأعمال؛ يمكنك قراءة نموذج التخرج أو تحميله في المحرر ثم تعديله وحفظه وتصديره.

من الإعدادات عدّل اسم العرض أو كلمة المرور أو خطة الدراسة. يبقى اسم الدخول ثابتًا. زر «تبديل المستخدم» يقفل الحساب قبل دخول مستخدم آخر، مع قفل تلقائي بعد٣٠ دقيقة خمول وحد أقصى١٢ ساعة. احفظ المسودات قبل ترك الجهاز. لا توجد مزامنة سحابية تلقائية.

من الإعدادات صدّر نسخة مشفّرة بعبارة حماية مستقلة واحتفظ بها خارج الجهاز. الاستعادة تستبدل بيانات الحساب الحالي بعد التحقق. لا توجد استعادة كلمة مرور عبر البريد؛ لا تخزن العبارة أو النسخة في المستودع. يمكن ربط بيانات النسخة القديمة مرة واحدة من شاشة الإعداد الأولي أو استيراد JSON قديم صالح.

التطبيق مستقل عن الإنترنت للتعلم العادي. روابط المراجع تفتح خارجيًا عند اختيارها. ملف Windows غير موقّع رقميًا؛ لم يُدّع وجود شهادة توقيع. تفاصيل ما اختُبر فعلًا في [سجل QA](docs/QA.md).

## نسخة الويب الاختيارية

`docker compose up --build -d` يبني ويخدم نفس المحتوى على http://127.0.0.1:8080 . هذا مسار للمشغّل التقني، وليس متطلبًا لنسخة Windows. هذا النشر يضم nginx وAPI منفصلًا بقاعدة SQLite في volume دائم `academy_data`. الحسابات على خادم هذا النشر، ويلزم الاتصال به للحفظ والدخول؛ لا توجد مزامنة تلقائية مع نسخة Windows. الحاويات تعمل دون root وبجذر ملفات للقراءة فقط. للنشر البعيد اضبط `APP_ORIGIN` إلى عنوان HTTPS الفعلي خلف وكيل TLS موثوق، ولتغيير المنفذ اضبط `ACADEMY_WEB_PORT` والعنوان معًا. لا تحذف volume عند التحديث. يوضح `compose.env.example` متغيري المنفذ والعنوان؛ يمكن نسخه إلى `.env` خاص عند الحاجة إلى تجاوز الافتراضات.

النسخة السابقة المحلية للمتصفح ما زالت متاحة عبر `docker compose -f compose.static.yaml up --build -d`. احتفظ بعنوان المتصفح وملفه للوصول إلى IndexedDB السابق؛ تسجيل الدخول الصحيح في النسخة الجديدة ينقل الحساب والتقدم إلى SQLite مع إبقاء الأصل. نسخة API لا تتحول إلى مخزن متصفح بديل عند انقطاع الخادم.

## تطوير واختبارات

Node.js 24 وnpm للتطوير فقط:

```sh
npm ci
npm run dev
npm run check
npm run test:e2e
npm run package:win
```

اختبارات المتصفح على Linux تستخدم Chromium المثبت أو `CHROMIUM_PATH`. يغطي CI بناء Windows الحقيقي واختبار الملف الناتج، والمتصفح وDocker. النشر عبر workflow الإصدار مشروط بنجاح التحقق لنفس commit. لا يكفي وجود ملف workflow لإثبات نجاح بناء أو إصدار؛ راجع نتائج التنفيذ.

## المصدر والمنهج والحدود

الدروس شروح وأنشطة أصلية تستفيد مفاهيميًا من الكتب الثلاثة المرفقة ومراجع رسمية محددة النطاق. تعرض إحالات كل درس وحقوقها وما تحقق منها؛ انظر [سجل المصادر](docs/SOURCE_REGISTRY.md). تحافظ نسخ التقييم على النص والدرجة السابقين للمحاولات القديمة، وتبدأ الإعادة بالأسئلة المراجعة دون حذف التقدم. لا تُرفق الكتب أو النصوص المستخرجة منها. كل بيانات الأمثلة والمشروعات النموذجية محاكاة موسومة، ولا تمثل نتائج عميل حقيقي. المراجعة التعليمية في هذه النسخة تحريرية وآلية بواسطة الوكيل؛ لا ندّعي مراجعة بشرية مستقلة أو اعتماد جهة تدريب.

المعمارية React/TypeScript مشتركة، مع SQLite في Electron main أو API، وDexie للحفاظ على المصادر القديمة ونسخة PWA الثابتة. تشفير AES-GCM لكل حساب وPBKDF2 بكلفة600,000 دورة. Electron يعمل بأصل محلي دون HTTP listener. [نموذج الأمان](docs/SECURITY.md) يشرح الحدود، بما فيها عدم حماية جهاز مخترق أو تحكم مسؤول نظام.

## التعلم بالمشروعات٢.٢.٠

١٢ دليل وحدة كاملًا بحلول وقوالب ومخرجات وروبرك وأخطاء وتحسين، و٦٠ مشروع درس مصغرًا، وثلاثة أمثلة تخرج كاملة لمطعم بغدادي وملابس الموصل وتجارة إلكترونية بالبصرة. يتدرج التخرج عبر١٢ مرحلة/٢٧ حقلًا، مع تحليل منافسين مستقل وخطة تساعية وتقويم وأصول وحسابات وتقرير عميل. كل أداء الأمثلة محاكاة. الحفظ التلقائي ينتظر التأكيد قبل تبديل الوحدة والتصدير، والنقل إلى ملف الأعمال يضيف التسليم بعد معاينة دون حذف النص السابق. تصدير ملف الأعمال يشمل تطبيقات الدروس وتسليمات الوحدات؛ النسخة المشفرة هي صيغة الاستعادة.

يمكن تنفيذ التدريب داخل التطبيق أو على الورق دون حساب إعلان أو اشتراك أو إنفاق. اختُبرت مشروعات الوحدات الاثنتي عشرة والحفظ وإعادة الفتح والتصدير دون شبكة، ومسار المشروع المصغر والتخرج على الهاتف ولوحة المفاتيح. نجح٥٧ اختبارًا لكل نظام و٢٥ مسار واجهة في التحقق النهائي، مع EXE فعلي وDocker وفحص تنزيل الملفات وبصماتها. هذا لا يعادل تجربة مبتدئ بشرية مستقلة، وهي ما زالت مفتوحة. ## تشغيل ملف Windows المحمول

الملف الرئيسي هو **Marketing-Academy-Portable-Windows-x64.exe**. افتحه مباشرة دون تثبيت Node.js أو Python أو Docker أو قاعدة بيانات. [دليل البدء العربي](docs/START_AR.md) · [التحقق الفعلي](docs/WINDOWS_PORTABLE_VERIFICATION.json). اختُبر التشغيل العادي للملف نفسه على Windows مع مسار بحث خالٍ من أدوات التطوير، والحساب والملاحظات وإكمال الدرس والاختبار دون شبكة والحفظ بعد إعادة الفتح وعزل الحسابات. هذا ليس اختبارًا يدويًا على جهاز مستخدم نظيف. الملف غير موقّع وقد يظهر SmartScreen؛ راجع دليل المصدر والبصمات قبل التشغيل ولا تعطّل حماية الجهاز.
